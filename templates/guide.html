操作指南

全面的新闻制作工作流程指南，帮助您高效地将英文新闻转化为微信图文内容

系统概览

LIVE Studio 是一个专业的新闻内容制作平台，专门用于将英文新闻转化为适合微信发布的中文图文内容。系统采用 AI 驱动的翻译和排版技术，大幅提升内容生产效率。

AI 智能翻译
自动提取文章内容，使用 Gemini AI 进行高质量翻译和内容重构，确保符合中文读者阅读习惯
专业图片生成
一键生成微信公众号专用长图，支持多学校品牌配色，自动排版封面图和正文
批量处理
支持多篇文章同时处理，顺序执行确保稳定性，任务进度实时可视化
便捷导出
支持单张下载和按学校批量打包下载，一键获取所有生成的图片资源

URL → 中文稿件

将英文新闻链接转化为专业的中文新闻稿件，自动生成 Google Docs 文档

1 粘贴新闻链接

在 "URL to Chinese News" 面板中，将英文新闻的完整 URL 粘贴到输入框中。

系统支持大多数主流新闻网站，包括：

  • 大学官方新闻网站 (news.nyu.edu, news.usc.edu 等)
  • 主流媒体 (NYT, WSJ, BBC, CNN 等)
  • 行业新闻网站
提示：可选填自定义标题，留空则自动从文章提取
2 点击 "Process URL" 开始处理

点击按钮后，任务会自动添加到左侧任务列表中。处理过程包括：

  • 内容提取 (5-10%)：自动抓取文章标题、正文、发布日期等信息
  • 英文摘要 (10-30%)：AI 生成符合中国读者视角的英文摘要
  • 中文翻译 (30-60%)：高质量翻译并进行风格调整
  • 文档导出 (60-100%)：自动创建 Google Docs 并格式化
3 查看处理结果

任务完成后，可通过以下方式查看结果：

  • 点击任务卡片上的 Google Doc 按钮直接打开文档
  • 点击 JSON 按钮查看完整的处理数据
  • 生成的稿件会自动出现在 "Google Doc to Images" 面板的文档队列中
注意：如果 Google Doc 创建失败，中文内容仍会保存在任务数据中，可通过 JSON 查看

稿件 → 微信图片

将已完成的中文稿件批量生成微信公众号专用长图

1 选择待生成的稿件

在 "Google Doc to Images" 面板中，您会看到所有已完成的中文稿件列表。

  • 点击稿件可以选中/取消选中
  • 支持多选，可同时处理多篇稿件
  • 也可以直接粘贴 Google Doc URL
2 选择学校品牌

从下拉菜单选择目标学校，系统会自动应用对应的品牌配色：

NYU 紫色 USC 红色 EMORY 深蓝 UCD 蓝色 UBC 深蓝 EDIN 藏青
3 生成并下载图片

点击 "Generate Images" 开始批量生成。任务会按顺序执行以确保稳定性。

生成完成后：

  • 点击任务卡片可以预览图片
  • 点击 Preview 按钮查看大图
  • 使用学校批量下载按钮一键打包下载
提示：生成的来源 URL 会自动加入来源汇总队列

文字 → 图片

直接输入中文内容生成微信长图，适合手动编辑或特殊排版需求

1 填写内容信息

在 "Text to Image" 面板中填写：

  • 学校：选择目标学校品牌
  • 标题：中文新闻标题
  • 内容：中文正文内容
  • 来源 URL（可选）：用于获取封面图和记录来源
2 生成图片

点击 "Generate Image" 按钮，系统会：

  • 从来源 URL 自动抓取封面图（如有）
  • 根据内容长度自动分页
  • 应用学校品牌配色
  • 生成高清 PNG 长图

来源汇总图

自动汇总本期所有新闻来源，生成专业的来源引用图片

1 自动汇总来源

系统会自动收集已生成图片的来源 URL，按学校分组显示在 "Sources Reference Image" 面板中。

您也可以：

  • 手动添加额外的来源 URL
  • 删除不需要的来源
  • 在每个学校分组中单独管理
2 生成汇总图

点击对应学校的 "Generate Sources Image" 按钮，生成该学校的来源汇总图。

来源汇总图包含：

  • 所有来源网站的完整 URL
  • 学校品牌配色
  • 专业排版格式
提示：建议在所有新闻图片生成完成后再生成来源汇总图

任务管理

左侧边栏显示所有任务的实时状态，支持筛选、预览和管理

任务筛选
使用顶部的 All / Doc / Img 按钮快速筛选任务类型。选择 Img 后还可以按学校进一步筛选
实时进度
每个任务卡片显示实时进度条，运行中的任务边框高亮，完成后变为绿色
快速预览
点击已完成的图片任务可直接预览大图，无需离开页面
任务删除
点击任务卡片右上角的 × 按钮可删除任务，已生成的文件不会被删除

下载与导出

多种下载方式满足不同需求

1 单张图片下载

点击任务卡片查看图片预览，在预览弹窗中点击 "Download" 按钮即可下载单张图片。

2 按学校批量下载

在左侧边栏中，筛选 Img 任务类型后，会显示学校快速下载按钮：

  • 点击学校下载按钮（带下载图标）
  • 系统自动打包当前会话中该学校的所有图片
  • 下载为 ZIP 压缩包

常见问题

Q: 为什么 Google Doc 创建失败？
A: 这通常是由于 Google OAuth 凭证过期或配置问题。请确保环境变量 GOOGLE_OAUTH_CREDENTIALS_JSON 和 GOOGLE_OAUTH_TOKEN_PICKLE_BASE64 已正确设置。即使文档创建失败，中文内容仍会保存在任务数据中，可通过点击 JSON 按钮查看。
Q: 任务卡在某个进度不动了怎么办？
A: 某些网站可能需要较长时间抓取，请耐心等待。如果超过 5 分钟仍无进展，可以删除任务重试。常见原因包括：目标网站有反爬机制、网络连接问题、或 AI API 响应延迟。
Q: 如何批量处理多篇文章？
A: 首先逐个添加 URL 到处理队列（每次粘贴一个 URL 并点击 Process URL）。所有任务会显示在左侧边栏中。待 URL 处理完成后，在 "Google Doc to Images" 面板中多选已完成的稿件，一次性生成图片。
Q: 图片生成后存在哪里？
A: 所有图片都保存在服务器的 wechat_images 目录下，按学校分类。例如 NYU 的图片在 wechat_images/NYU_Weekly/ 目录。您可以通过界面下载，或直接访问服务器文件系统。
Q: 支持哪些新闻网站？
A: 系统使用通用网页抓取技术，理论上支持所有公开的新闻网站。对于有付费墙或需要登录的网站，可能无法正常抓取内容。建议使用学校官方新闻网站或主流媒体的公开文章。
